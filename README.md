# SVO Ambiental - Sitio Web Corporativo

Este es el repositorio oficial del sitio web de **SVO Ambiental**, una consultoría legal especializada en derecho ambiental con base en Chile.

## 🚀 Despliegue Rápido

### Opción A: Netlify (Recomendado)
1. Ve a [Netlify](https://www.netlify.com/).
2. Arrastra y suelta la carpeta raíz del proyecto en el panel de Netlify.
3. El sitio estará en línea en segundos.

### Opción B: GitHub Pages
1. Sube este código a un repositorio público en GitHub.
2. Ve a **Settings** > **Pages**.
3. Selecciona la rama `main` y la carpeta `/(root)`.
4. ¡Listo!

## ⚙️ Configuración Final del Cliente

Para que el sitio sea totalmente funcional, abre `index.html` y busca las siguientes líneas para reemplazarlas con la información real:

1. **WhatsApp**: Busca `wa.me/569XXXXXXXX` y cámbialo por el número real del cliente (ej. `wa.me/56912345678`).
2. **Calendly**: Busca `calendly.com` y cámbialo por el enlace de reserva del cliente.
3. **LinkedIn**: Busca `linkedin.com` y vincula el perfil profesional del abogado.

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica para SEO.
- **CSS3 Vanilla**: Diseño premium personalizado sin frameworks pesados.
- **JavaScript**: Animaciones de "Reveal-on-scroll" y navegación suave.
- **Google Fonts**: Playfair Display e Inter.
